# Instructions du projet

Ces instructions sont le point d'entrée de Claude Code pour tout le dépôt.
Les règles communes sont dans `AGENTS.md` et les règles propres à chaque partie
se trouvent dans `client/` et `server/`.

@AGENTS.md

## Structure connue

- `client/` : application frontend. Voir `client/CLAUDE.md` et `client/AGENTS.md`.
- `server/` : application backend. Voir `server/CLAUDE.md` et `server/AGENTS.md`.
- `README.md` : présentation et documentation générale du projet.

La stack, les commandes de développement et les détails d'architecture restent
à documenter à partir des manifests et de l'implémentation lorsqu'ils seront
présents. Ne pas les supposer.
