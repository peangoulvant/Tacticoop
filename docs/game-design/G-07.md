# G-07 — Actions des unités

Ce chapitre définit détection et brouillard de guerre. Les points ouverts sont regroupés dans [DECISIONS.md](DECISIONS.md) ; les comportements détaillés figurent dans les [SF](../functional-specs/README.md).

| ID | Statut | Règle |
|---|---|---|
| G-07.1 | VALIDÉ | Une activation comporte au maximum un déplacement et une action spéciale facultative, dans n'importe quel ordre. |
| G-07.2 | VALIDÉ | Actions envisagées : recherche sonar, préparation de torpille, préparation d'hélicoptère ASM, réparation. |
| G-07.3 | VALIDÉ | Un balayage de détection consomme l'action spéciale de l'unité. Résolution et révélation : G-08.3.6 (AB-25). |
| G-07.4 | PROPOSÉ | Chaque action a des préconditions explicites : unité compatible, état, cible, portée, ressources. |
| G-07.5 | À DÉFINIR | Catalogue exhaustif, portée et coût des actions, temps de préparation, munitions, combat, réparation, hélicoptères. |
| G-07.7 | VALIDÉ (AB-30) | **Balayage :** actions autorisées si l'unité est activable, son action spéciale non utilisée, qu'elle porte des capteurs (frégate, sous-marin) et que la mission est en cours ; sinon refus motivé sans consommation. Aucun paramètre : elle vise toute la zone à portée. Confirmation explicite, annulation sans coût ; l'action est consommée même sans résultat. Aucun effet sur la discrétion (G-08.3.5, AB-29). |
| G-07.8 | VALIDÉ (AB-34) | **Délai de récupération :** après son usage, une action spéciale reste indisponible un nombre de cycles configurable (1 pour le balayage : faite au cycle 3, impossible au cycle 4, de nouveau possible au cycle 5). Le bouton de l'action affiche une horloge et le nombre de cycles restants (amélioration visuelle demandée par le propriétaire, remplace le texte d'explication). Le mécanisme est commun à toutes les actions spéciales à venir ; chacune a sa valeur. |
| G-07.6 | À DÉFINIR | Effets d'une action échouée, annulation, validation de l'ordre, actions contre des zones approximatives. |

**Frontière :** les attaques, dégâts et armes seront détaillés dans **G-09**, non spécifiés par anticipation.

---

## Séquence d'une activation

 le joueur choisit l'ordre entre mouvement et action spéciale. Une activation peut comporter au maximum **un mouvement** et **une action spéciale facultative**. Il n'est pas possible de réaliser deux recherches actives pendant la même activation.

### Actions évoquées

| Action | Intention | Maturité |
|---|---|---|
| Déplacement | Repositionner l'unité dans sa limite de mobilité | Principe VALIDÉ |
| Balayage (ex-« recherche sonar active ») | Améliorer la détection, selon G-08 | Principe VALIDÉ |
| Préparer une torpille | Préparer un engagement futur | ÉVOQUÉ ; conditions À DÉFINIR |
| Préparer un hélicoptère ASM | Préparer un moyen de lutte anti-sous-marine | ÉVOQUÉ ; conditions À DÉFINIR |
| Réparer | Restaurer un composant ou un état | ÉVOQUÉ ; effets À DÉFINIR |
| Tirer | Engager une cible | À DÉFINIR en G-09 |

**PROPOSÉ :** chaque action devra avoir des préconditions testables (unité compatible, portée, munitions, état, cible) et des résultats observables pour le journal.

Ne pas supposer qu'une torpille préparée est tirée immédiatement, ni qu'un hélicoptère peut être utilisé par toutes les frégates : ces mécaniques n'ont pas été arrêtées.

## Précision V1 — hélicoptères ASM

Les fiches provisoires retiennent un hélicoptère pour la FREMM et la frégate DA, deux pour la frégate ASM. **Un seul hélicoptère peut être utilisé à la fois par frégate**. Le second d'une frégate ASM est une réserve mobilisable si le premier est détruit. Les règles déjà définies de déploiement, activation et récupération restent applicables ; aucune nouvelle action n'est introduite. Le porte-avions n'a pas d'action spéciale.
